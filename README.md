# ExpenseEase

A simple expense tracker mobile app built with **React Native (Expo)**.

## Features
- Add, edit and delete expenses
- Live total spent on the home screen
- Summary by spending category with percentage bars
- Offline persistence with AsyncStorage
- Input validation and delete confirmation

## Tech Stack
React Native, Expo SDK 57, React Navigation, React Context API, AsyncStorage, JavaScript.

## Run locally
```bash
npm install
npx expo start
```

Use Expo Go on a phone or an Android emulator.
